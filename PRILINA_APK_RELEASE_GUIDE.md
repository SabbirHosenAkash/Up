# Publishing a new Prilina APK

The portfolio is hosted on GitHub Pages, which is a static hosting service. It cannot safely accept and permanently store an APK uploaded through a public website form.

To publish or replace the APK:
1. Open the repository: https://github.com/SabbirHosenAkash/sabbirhosenakash.github.io
2. Open **Releases** → **Draft a new release**.
3. Create a release tag (for example `v1.0.0`).
4. Attach your `Prilina.apk` file under **Attach binaries**.
5. Publish the release.

The **Download Prilina APK** button on the portfolio opens the latest published release. Uploading a newer APK to a new release automatically makes that release the destination for visitors.

Do not put a GitHub personal access token or password in website JavaScript.
