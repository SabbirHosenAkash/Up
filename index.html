PRILINA — Autonomous AI Agent

Prilina is an autonomous AI agent project designed to move beyond ordinary chat: the goal is to understand user instructions, plan multi-step workflows and coordinate actions through an extensible agent architecture.

Its development direction brings together local GGUF language models, llama.cpp-based inference, Android integration, native JNI/NDK components, a Macro Engine and memory management—while keeping the architecture open for future model families.
